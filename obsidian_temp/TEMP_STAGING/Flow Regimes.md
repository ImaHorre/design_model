# Flow Regimes

*Dripping, transitional, and jetting regimes in microfluidic droplet formation*

## Regime Classification

**Dripping Regime** (Target operation):
- Low capillary number (Ca << 0.01)
- [[Surface Tension]] dominance
- Predictable [[Critical Radius]] mechanism
- Monodisperse droplet production

**Transitional Regime** (Avoid):
- Intermediate capillary number (Ca ~ 0.01-0.3)
- Mixed physics mechanisms
- Unpredictable behavior and size distributions
- Sensitive to small parameter changes

**Jetting Regime** (Control/avoid):
- High capillary number (Ca >> 0.3)
- Viscous force dominance
- Continuous jet formation
- Downstream Rayleigh-Plateau breakup
